# PROMPT COMPLET — CRÉATION DU SITE VITRINE SMARTSHOP À PARTIR DU BMC

Tu es un assistant pédagogique expert en création de sites web simples pour des étudiants totalement débutants.

L’étudiant n’a jamais créé de site web, utilisé un éditeur de code ou travaillé avec un terminal.

Ta mission est double :

1. Créer un site vitrine complet adapté au projet **ELORA** et à son Business Model Canvas.
2. Guider l’étudiant pas à pas pour ouvrir le projet, comprendre les fichiers, lancer le site localement et afficher le résultat dans son navigateur.

Utilise un langage simple. Explique chaque étape sans supposer de connaissances techniques. Ne donne pas seulement du code : explique aussi comment l’utiliser.

ELORA.

**Canaux :**

## 3. CHARTE GRAPHIQUE ET IDENTITÉ VISUELLE

### Logo

Aucun fichier de logo n’a été fourni.

Créer une signature typographique simple avec le nom **ELORA** :

- « Smart » en bleu nuit.
- « Shop » en bleu électrique.
- Éventuellement, un petit symbole original de sac de shopping associé à un éclair, réalisé en SVG simple.

### Palette de couleurs

| Rôle | Couleur | Code |
|---|---|---|
| Couleur principale | Bleu électrique | `#2563EB` |
| Couleur secondaire | Bleu nuit | `#0F172A` |

**Utilisation :**

- Bleu électrique : boutons principaux, liens et éléments actifs.
- Bleu nuit : titres et pied de page.
- Cyan : petits accents graphiques et éléments décoratifs.
- Gris très clair : fond général.
- Blanc : cartes produits.

Ne pas utiliser le cyan pour de petits textes sur fond blanc. Vérifier la lisibilité et le contraste des textes et des boutons.

### Style souhaité

Moderne, technologique, accessible, jeune et professionnel.

L’interface doit évoquer la simplicité et la confiance, avec des espaces aérés, des cartes claires et des visuels produits bien mis en valeur.

### Typographie

Utiliser une police sans empattement lisible, disponible localement :

```css
font-family: "Segoe UI", Arial, sans-serif;
```

- Titres : gras.
- Texte courant : au moins 16 px.
- Interligne : environ 1,6.
- Titres courts et hiérarchie visuelle claire.

### Composants

- Boutons avec coins arrondis de 10 px.
- Cartes avec coins arrondis de 16 px.
- Ombres légères.
- Espacements réguliers fondés sur 8, 16, 24, 32 et 48 px.
- Effets de survol discrets.
- Indicateurs de focus visibles pour la navigation au clavier.

Conserver cette identité sur toutes les pages.

### 3. `bagues.html` — Catégorie à la une

### 5. `contact.html` — Contact

Prévoir :

- Un emplacement pour l’e-mail.

- Un emplacement pour les réseaux sociaux.
- La zone de livraison, lorsqu’elle sera confirmée.
- Un formulaire de démonstration : nom, e-mail et message.

Tant que les coordonnées ne sont pas fournies, afficher « Coordonnées à renseigner » sans créer de faux liens.

Après validation, afficher :

Ne pas enregistrer les données saisies.

## 15. LANCEMENT DU SITE EN LOCAL

### Méthode 1 — Ouverture directe

1. Ouvrir le dossier `elora`.
2. Double-cliquer sur `index.html`.
3. Le site s’ouvre dans le navigateur.

Cette méthode doit permettre de consulter toutes les pages et les interactions prévues.

### Méthode 2 — Serveur local avec Python

Si Python est installé, vérifier sa disponibilité :

```bash
python --version
```

Puis, dans le dossier `elora`, lancer :

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Selon l’installation, utiliser `python3` ou `py` à la place de `python`.

Expliquer que cette commande rend le site accessible sur l’ordinateur à l’adresse :

```text
http://localhost:8000
```

Garder le terminal ouvert pendant la consultation.

Pour arrêter le serveur :

```text
Ctrl + C
```

Si Python n’est pas reconnu, proposer l’ouverture directe ou la méthode sans terminal.
